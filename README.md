# 💤 SNOOZE – Sleep Tracker Web App

A simple Flask-based web application to track daily sleep habits and build consistency.

---

## 🚀 Features

* User registration system
* Add daily sleep entries (date, sleep time, wake time)
* View all past sleep records
* Clean and minimal UI using HTML, CSS, and Bootstrap

---

## 🛠️ Tech Stack

* **Backend:** Flask (Python)
* **Database:** SQLite (SQLAlchemy)
* **Frontend:** HTML, CSS, Bootstrap
* **Forms:** Flask-WTF

## ⚙️ How to Run Locally

1. Clone the repository

```
git clone https://github.com/ishitaA0704/FLASK-PROJECT-SLEEP-TRACKER-.git
```

2. Navigate to the project folder

```
cd FLASK-PROJECT-SLEEP-TRACKER-
```

3. Install dependencies

```
pip install -r requirements.txt
```

4. Run the app

```
python app.py
```

5. Open in browser

```
http://127.0.0.1:5000
```
